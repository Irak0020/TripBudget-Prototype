# TripBudget Prototype – Capstone Project Part 3

## Overview
This prototype was created using HTML, CSS, and JavaScript as part of the Capstone Project Part 3. The goal was to develop a responsive and functional prototype that closely matches the mockup created in Part 2.

---

## Steps Taken

1. Created a new Git branch called:
   feature-prototype-part3

2. Built the HTML structure using semantic elements:
   - Header
   - Hero section
   - Search section
   - Results section
   - Footer

3. Designed the layout using modern CSS techniques:
   - Flexbox for navigation and forms
   - CSS Grid for trip cards
   - Media queries for responsiveness

4. Implemented a simple JavaScript interaction to simulate search workflow.

5. Tested responsiveness across different screen sizes using browser developer tools.

6. Validated HTML and CSS using W3C Validator.

---

## Responsiveness

- Used CSS Grid for trip cards layout
- Used Flexbox for navigation and form layout
- Used media queries (min-width: 768px)
- Mobile-first design approach

---

## Resources Used

- W3Schools
- MDN Web Docs
- CSS Grid and Flexbox documentation
- Google Chrome Developer Tools

---

## Challenges Faced

- Ensuring layout remained consistent across screen sizes
- Balancing design aesthetics with responsiveness
- Matching the prototype closely with the mockup

---

## Conclusion

The prototype demonstrates a nearly complete workflow:
User can search → view trips → see total cost → simulate booking.

The design is responsive and uses modern CSS techniques.
